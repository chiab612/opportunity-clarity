# 機會透明評估工具 Opportunity Clarity

以原生 HTML、CSS、JavaScript 製作的繁體中文離線網頁，協助報名前整理活動費用、時間、參與條件與公開資訊。這是資訊整理工具，不評定個人或主辦單位，也不把資訊缺漏當作不公平、舞弊或惡意的證據。

## Windows 啟動

1. 將 `index.html`、`style.css`、`app.js` 放在同一個資料夾。
2. 在檔案總管中直接雙擊 `index.html`，或按右鍵選擇瀏覽器開啟。
3. 點「載入示範活動」試用，或填入自己的活動資料。無須安裝程式、啟動伺服器或連上網路。

## 功能

- 輸入報名費、交通費、其他必要支出、活動時間、補助及五項公開參與資訊。
- 分開比較估算支出與預算、活動時間與可投入時間，並計算資訊完整度。
- 列出尚未提供的資訊與可在報名前提出的確認問題。
- 載入不含真實活動或個人資料的示範案例；重新分析、重設、清除資料。
- 複製分析摘要、下載 UTF-8 文字報告。
- 表單會自動存在目前瀏覽器的 `localStorage`，不會自動上傳。
- 桌面及手機版面、欄位錯誤提示與鍵盤焦點狀態。

## 計算方式與限制

- 預估支出＝報名費＋預估來回交通費＋其他必要支出。三個欄位都填妥後才顯示總額；空白代表未知，不當成零元。補助不會自動扣抵，因為補助金額、適用資格及核銷方式可能不同，請在備註記錄並向主辦方確認。
- 預算及時間僅在兩邊資料都填妥時進行比較。未提供資料會顯示「資料不足」，不自行推測。
- 資訊完整度共檢視五項：參加資格、錄取及候補規則、評選標準及權重、無障礙及參與需求、取消／退費／變更規則。每項等權 20%；有說明或註明不適用即算已交代。這不代表活動公平性、品質或主辦方意圖。
- 本工具不驗證來源網址內容，也不會判斷主辦方說明是否正確。建議記錄公告原文及更新日期。
- 不要在選填備註中填入姓名、身分證字號、診斷或其他可識別的敏感資料。使用共用裝置時請按「清除資料」，或清除該瀏覽器的網站資料。
- 「重設表單」會將表單欄位恢復空白，但保留瀏覽器中空白表單狀態；「清除資料」會同時刪除本工具的本機儲存項目。

## 檔案

- `index.html`：介面結構及欄位。
- `style.css`：響應式樣式。
- `app.js`：驗證、分析、示範、瀏覽器本機儲存與報告匯出。
- `README.md`：使用及計算說明。

本專案沒有外部函式庫、API、API 金鑰、付費服務、外部字型或網路依賴。
